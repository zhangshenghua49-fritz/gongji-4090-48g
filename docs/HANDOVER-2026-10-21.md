## 5. 今天踩的坑（别重踩）

1. **转速过快被用户质疑**：用户明确说「我不相信你在一个小时之内能搞定」。明天**先出最小可验证结果再扩展**，不要一次铺 8 个文件。
2. **bgdesk 把 Edge `stage adopt` 到屏幕外后，Chromium 停止渲染**，`printwindow` 截图永远是同一帧缓存 → 看不到页面真实变化。解法：`stage release` 还原到屏幕内，或改用 UIA `find` 读元素（UIA 能读到 offscreen 元素）。
3. **`postmessage-keys` 对 Chromium 滚动无效**，`{PGDN}` 打不动页面。有效的是：① UIA `ScrollItemPattern.ScrollIntoView()`；② `act click` 页面空白处聚焦后再发键。
4. **UIA `Invoke()` 对不可见元素静默返回 ok 但无效果**。判断按钮是否可见：看 `IsOffscreen` 和 rect 是否在可视区内。
5. **`BoundingRectangle` 可能返回 `±∞`**，`[int]` 转换会抛 `Cannot convert value "∞"`，必须 try/catch 包裹。
6. **番茄小说正文拿不到**：公开页 `https://fanqienovel.com/page/7697640572990786585` 返回 404；只有目录 API 可用（`/api/reader/directory/detail?bookId=`），正文接口全部 404 或空响应。**小说正文只能用户自己提供**。
7. **误操作事故**：向 RootElement 枚举 Button 匹配「新增部署任务」时，命中的是页面内同名按钮，Invoke 后把已填好的表单**重置**了。不要靠名字匹配全局元素去操作任务栏。
