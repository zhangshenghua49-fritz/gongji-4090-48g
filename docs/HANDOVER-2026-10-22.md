## 7. 已解决的关键坑（别重踩）

1. **`df -h / "$DATA"`**：`$DATA` 不存在时返回 1，配 `set -e` 让整个装配静默退出。先 `mkdir -p`。
2. **`_here="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"`**：前面 `cd "$COMFY"` 之后相对路径就废了。改成脚本第 21 行算好 `SCRIPT_DIR` / `PROJECT_DIR`。
3. **`pyopenjtalk` 编译要 `Python.h`**：apt 必须带 `python3-dev python3-venv`。
4. **GitHub Actions `matrix` 里不能用 `inputs.*`**：`push` 事件下不存在，workflow 会变 0 job。用 `setup` job 把 `github.event.inputs.flavor` 翻成 JSON 数组。
5. **GitHub tree API 的 `encoding: base64` 会被静默忽略**：必须走 `POST /git/blobs`。踩过一次，36 个文件全成乱码。
6. **gated 权重仓匿名 403**：`black-forest-labs/flux-3-image-klein-comfy` 与 `Lightricks/LTX-2.5` 都是 `gated=auto`。换成逐项等价的非 gated 镜像：`ml-resources/flux-3-image-klein-comfy`、`comfyicu/LTX-2.5`。
7. **hf.co / huggingface.co 直连超时**：用 `https://hf-mirror.com/api/models/{repo}/tree/main?recursive=true` 拿逐文件字节。脚本在 `.cache/probe.py`（`probe.py tree REPO` / `probe.py search Q`）。
8. **`XXXXRT/GPT-SoVITS-Pretrained` 没有 V5 权重**：v5 在 `lj1995/GPT-SoVITS`，路径**没有** `pretrained_models/` 前缀。
9. **ComfyUI `models/` 里已有空目录**：软链前要判断是否为空，空才 `rmdir` 再链。
